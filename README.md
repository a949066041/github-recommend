## 仓库结构

```
.
├── README.md              # 说明、阅读方式，以及「最新」一节
└── daily/
    └── YYYY-MM-DD.md      # 当天完整推荐（精选 + 补充观察）
```

- `daily/YYYY-MM-DD.md`：按日期归档，一天一个文件，内容保持当天整理时的表述。
- `README.md`：入口页。只在「最新」一节放当天链接和短预览，历史日期留在 `daily/`。

## 后续怎么加一天

1. 新增 `daily/YYYY-MM-DD.md`，沿用现有每日文件的结构（标题、来源、今日精选、补充观察）。
2. 更新本 README 的「最新 · YYYY-MM-DD」：改日期、链到新文件，并替换前五条预览。
3. 已归档的日期文件一般不再改写；只有勘误时才回改对应文件。
